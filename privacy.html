한국어English

honeypolicy(이하 "서비스")는 「개인정보 보호법」에 따라 이용자의 개인정보를 보호하고, 이와 관련한 고충을 처리하기 위해 다음과 같이 개인정보처리방침을 둡니다.

1. 처리하는 개인정보와 목적

서비스는 시청자의 개인정보를 수집하지 않습니다. 웹페이지에는 회원가입, 로그인, 쿠키 기반 추적, 광고 분석 도구가 없습니다.

서비스가 처리하는 개인정보는 운영자 본인의 틱톡 계정을 연동할 때 틱톡이 제공하는 아래 정보뿐입니다.

항목목적보유 기간
틱톡 계정 식별자(open_id), 공개 표시 이름연동된 계정 확인연동 해제 시 즉시 삭제
(갱신 토큰은 발급 후 최대 365일)
접근 토큰·갱신 토큰, 허용된 권한 범위(scope)운영자 계정으로 영상 초안 전송
업로드 기록(전송 시각, 처리 상태, 틱톡이 돌려준 게시 ID)중복 전송 방지, 오류 확인

틱톡 연동에서 요청하는 권한은 user.info.basic(계정 기본 정보)과 video.upload(초안 업로드)뿐이며, 팔로워·좋아요·메시지 등 다른 정보는 요청하거나 저장하지 않습니다.

2. 제3자 제공과 처리 위탁

서비스는 개인정보를 제3자에게 제공하거나 판매하지 않습니다. 영상 초안을 전송하기 위해 틱톡(TikTok) API와 통신하는 것 외에 개인정보를 외부로 보내지 않습니다.

참고: 영상 대본을 만들 때 쓰는 AI(Anthropic Claude API)에는 공개된 정책뉴스 본문만 보내며, 개인정보는 보내지 않습니다.

3. 파기 절차와 방법

보유 기간이 끝나거나 연동을 해제하면 데이터베이스에서 해당 정보를 지체 없이 삭제합니다. 운영자는 틱톡 앱의 설정에서 언제든지 서비스와의 연동 권한을 해제할 수 있습니다.

4. 안전성 확보 조치

  • 접근 토큰과 갱신 토큰은 데이터베이스에 저장할 때 암호화(AES-GCM)합니다.
  • 서비스 관리 기능은 운영자만 사용할 수 있도록 별도의 관리 키로 보호합니다.
  • API 키와 비밀 값은 소스 코드에 넣지 않고 환경 변수로만 관리합니다.

5. 정보주체의 권리

정보주체는 개인정보의 열람, 정정, 삭제, 처리 정지를 요구할 수 있습니다. 아래 연락처로 요청하면 지체 없이 처리합니다.

Privacy Policy (English)

Effective date: October 17, 2026. If the Korean and English versions differ, the Korean version prevails.

1. What we process and why

honeypolicy (the "Service") does not collect personal information from viewers. Its web pages have no sign-up, login, cookie-based tracking or advertising analytics.

The only personal information the Service processes is the following data provided by TikTok when the operator connects the operator's own TikTok account:

DataPurposeRetention
TikTok account identifier (open_id) and public display nameConfirming which account is connectedDeleted immediately when the connection is removed
(refresh tokens expire at most 365 days after issuance)
Access token, refresh token and granted scopesSending video drafts to the operator's account
Upload records (time, processing status, publish ID returned by TikTok)Preventing duplicate uploads and troubleshooting

The integration requests only the user.info.basic and video.upload scopes. It does not request or store followers, likes, messages or any other data.

2. Sharing and processors

The Service does not sell or share personal information with third parties. Apart from communicating with the TikTok API to send video drafts, no personal information leaves the Service. The AI service used to write scripts (Anthropic Claude API) receives only public policy news text, never personal information.

3. Deletion

Data is deleted from our database without delay when its retention period ends or the connection is removed. The operator can revoke the Service's access at any time in the TikTok app settings.

4. Security

  • Access and refresh tokens are encrypted (AES-GCM) before being stored.
  • Administrative functions are protected by a separate admin key available only to the operator.
  • API keys and secrets are never stored in source code and are provided only through environment variables.
